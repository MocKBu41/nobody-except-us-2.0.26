# BOT MEMORY

`BOT_LOGIC_CURRENT.json` — **каноническая постоянная логика поведения NEU BOT**.

Правило работы:
1. Перед любым изменением поведения бота сначала читать `GITHUB_MEMORY.md` и этот JSON.
2. Если пользователь сообщает новое правило поведения, изменение приоритета, дистанции, состава, условия покупки/вызова или перехода состояния — сначала обновить `BOT_LOGIC_CURRENT.json`, затем синхронизировать код текущей версии.
3. Изменение считается `НУЖЕН ТЕСТ`, пока не проверено игровым логом.
4. После теста использовать `/LOG/` и обновить статус в `GITHUB_MEMORY.md`.
5. Источник начальной схемы: пользовательский `BOT_logic_editor.html`, полученный 2026-09-14.

Текущая реализация схемы: `BOT_GPT/v2_0/`.
