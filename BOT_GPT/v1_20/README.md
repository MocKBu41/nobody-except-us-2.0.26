# NEU BOT v1.20

Полный комплект на основе активной v1.19 (коммит 0f5ef73bf53df112c8390764ef0645a50ae34777). Старые снапшоты не изменяются.

## Установка

Скопировать все файлы `bot*.lua` и оба JSON из этой папки в `mods/nobody except us 2.0.26/resource/script/multiplayer/` с заменой. Начать новый матч. Папку tests копировать в игру не требуется.

Загрузка: bot.main.lua → bot.v1_20.logic.lua → bot.v1_20.core.lua. bot.lua также перенаправляет на v1.20. Зависимостей от файлов v1.18/v1.19 нет. bot.data.lua, bot.mapdata.lua и обе базы карт включены.

## Изменения

- Потеря своей точки, включая переход в нейтральную, немедленно открывает контратаку. Одна БТГ назначается на возврат; первые две волны закреплены за целью. После двух неудач приоритет этой точки откладывается на 120 секунд, позволяя сменить направление.
- Свободные БТГ предпочтительнее; среди остальных расстояние оценивается по предыдущей цели/точке сбора. Это приближение, не реальные координаты отрядов.
- Оставшиеся нейтрали больше не блокируют наступление. Завершение стартового захвата не сбрасывает действующие атаки. Приказы на нейтральные флаги разрешены.
- Потерянная промежуточная точка заменяется своей. Пехота и техника используют общий случайный промежуточный флаг; выбор меняется между волнами, если карта позволяет. Точный путь между флагами выбирает движок.
- Сбор занимает минимум 30 секунд; при недостатке пехоты ожидание продолжается до 60 секунд, после чего допускается атака имеющимся отрядом. При нуле отрядов ожидание продолжается. Подход — 25 секунд. Это таймеры, не проверка физического прибытия.
- Каждые 3 секунды проверяется Scene.Squads — механизм из оригинального Cold War. Неизвестный управляемый отряд после 8 секунд ожидания включается в БТГ с меньшим числом пехотных отрядов и получает её текущую цель. Событие GameSpawn без подтверждения в Scene.Squads не даёт права на управление.
- Повторное событие известного отряда сбрасывает задержку следующего приказа и не забирает билет следующей покупки. Повтор приказов — каждые 5 секунд.
- Глобальный КД aircraftlight минимум 360 секунд; резервируется при запросе и продлевается от фактического появления. Уничтожение самолёта не отменяет КД. Новый матч сбрасывает таймер. Вертолёт patrol_heli имеет прежние правила.
- Сохранён случайный общий пул duel_tanks70 / duel_tanks80 / duel_tanks90.

## Ограничения и диагностика

Связь «конкретный транспорт → пассажиры», тип неизвестного отряда и факт высадки не доступны через подтверждённые методы. Scene.Squads позволяет подобрать управляемый резерв без GameSpawn, но не гарантирует обнаружение всех пассажиров и правильную исходную БТГ. Неизвестные управляемые отряды пока получают роль infantry_detached, как резерв; это не распознавание типа entity. В игре необходимо проверить, появляются ли высаженные отделения в Scene.Squads.

Enemy Scanner раз в 30 секунд безопасно вызывает подтверждённый оригинальным ботом Commands:EnemyHasTanks() и один раз перечисляет доступные имена полей API. Не вызывает неизвестные методы. Список техники, её количество, ПВО, координаты и привязка к секторам пока НЕ реализованы. Эти возможности явно выводятся как unavailable; сообщения не означают отсутствие противника. Сведения о танках пока диагностические и не меняют покупки.

Ключевые строки game.log: START v1.20, LOST FLAG, RETAKE ASSIGN, FRONT ROUTE REPAIR, OWN SCAN NEW, OWN RESERVE ADOPT, KNOWN SQUAD EVENT, ENEMY SCAN, API CAPABILITIES, AIR ARRIVED.

## Проверка

Регрессионный сценарий tests/regression.lua выполнен на Lua 5.4 с имитацией BotApi: потеря/возврат флагов, две волны контратаки, нейтральные цели, сохранение атак, обнаружение отрядов без GameSpawn, фильтрация неподтверждённых событий, повторное событие, глобальный КД и сброс матча, отсутствие EnemyHasTanks. Проверки прошли. Проверка в движке MoWAS2 не выполнялась; реальная высадка, проходимость и синхронность требуют игрового лога.

Для запуска теста из папки версии: `lua tests/regression.lua`.
