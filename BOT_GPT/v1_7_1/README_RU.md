# NEU BOT v1.7.1

Основа: v1.7. Версия сделана по результатам `game(7).log` без использования v1.6 guard/probe и без перехвата методов BotApi.

## Что изменено

1. Потеря танка больше не останавливает направление. Лог: `TANK LOSS CONTINUE`. Бот вызывает `duel_tanks80/90` на замену, дополнительную пехоту, AAT и `aircraftlight` (если для текущей армии есть кандидат).
2. Направление останавливается только после потери всей основной штурмовой пехоты группы во время атаки. Если в группе осталась другая живая штурмовая пехота, атака продолжается.
3. После остановки направления включено автоматическое восстановление через `DirectionRecoverySec = 30`: новая пехота + новый `duel_tanks80/90`, затем группа выбирает другой вражеский флаг, по возможности не повторяя проваленную цель.
4. Автоматическое присваивание любого неизвестного squad роли `infantry_detached` отключено. Неизвестные squads игнорируются, чтобы бот не спамил приказами чужим/не связанным подразделениям.
5. Одновременно на нейтральных точках резервируется не более `NeutralCaptureMaxActive = 3` двухбойцовых групп. Размер захватчиков остаётся `MaxSquadSize=2`.
6. Строгий порядок сохранён: пока есть хотя бы одна нейтральная точка, основные БТГ не начинают атаку вражеских флагов.
7. Две БТГ продолжают выбирать разные вражеские направления.
8. Сохранены 2-минутная проверка атаки, ПВО-патруль, оборона при преимуществе по флагам, 5-минутные подкрепления, ветки AAT/авиации.

## Важные ограничения

- `Spawn(..., 2)` создаёт отдельную двухбойцовую группу; проверенной команды `SplitSquad` для отделения двух конкретных солдат из существующего отделения пока нет.
- Точное удержание танка на расстоянии 100 игровых метров пока не реализовано: у проверенного BotApi не найдены команды координатного `Move/Stop` и надёжные координаты флага.
- Для USA в последнем логе роли `aircraftlight`, `antirad`, `strike`, `duel_heli`, `duel_fighter` имели `0 candidates`. v1.7.1 не подставляет выдуманные юниты: нужны реальные теги/записи из multiplayer units, чтобы безопасно расширить эти роли.

## Проверка в game.log

На старте:

```text
[NEU-BOT] START v1.7.1
[NEU-BOT] RULE two-BTG=ON strict-neutral-first=ON capture-pair-size=2 capture-max=3
[NEU-BOT] RULE tank-loss-keeps-direction=ON main-infantry-loss-stops=ON direction-rebuild=ON detached-auto=OFF
```

При потере танка:

```text
[NEU-BOT] TANK LOSS CONTINUE group=...
```

При разгроме основной пехоты:

```text
[NEU-BOT] DIRECTION STOP group=... lostRole=infantry rebuildAt=...
```

Через 30 секунд:

```text
[NEU-BOT] DIRECTION REBUILD group=... failed=... freshInfantry=YES freshTank=YES
[NEU-BOT] ATTACK START group=... flag=... previousFailed=...
```

В строках статуса `RES=` показывает число активных/зарезервированных двухбойцовых захватчиков. Значение не должно превышать 3.

## Установка

Скопировать из `BOT_GPT/v1_7_1/` в `script/multiplayer/`:

- `bot.lua`
- `bot.data.lua`
- `bot.main.lua`

Старые `bot.assault2.lua`, `bot.guard.lua`, `bot.probe.lua` не подключать.
