# NEU BOT v1.3

Исправление поведения по `game — копия (3).log` поверх v1.2.

## Что было неправильно

1. Стартовые пехотные отряды создавались без цели и до начала стратегической атаки могли стоять/ехать не туда.
2. Флаги сортировались как строки: `f1, f10, f11, f2...`, поэтому после `f1` бот мог выбрать `f10`, хотя логичнее продолжать по ближайшему фронту.
3. После автоматического спешивания пехоты первоначальный `CaptureFlag` мог больше не двигать пешую часть отряда.

## Исправлено

- Стартовые `recon + infantry + infantry + tank` сразу получают `OPENING FLAG`.
- Строковая сортировка флагов удалена.
- После появления своих точек следующая цель выбирается по минимальной числовой дистанции между именами флагов. Например, от `f1` при возможности выбирается `f2`, а не `f10`.
- Пехоте каждые 5 секунд повторно отдаётся `CaptureFlag` на текущую цель (`INFANTRY PUSH`). Это нужно, чтобы после спешивания пешая часть продолжала движение и атаку.
- Дополнительно бот просматривает `BotApi.Scene.Squads`. Если после спешивания/разделения появился новый squadId, он помечается как `infantry_detached` и получает текущую цель (`DETACHED squad=...`).
- Неизвестный `GameSpawn`, не связанный с очередью покупки, также получает текущую пехотную цель вместо простоя.
- Танки по-прежнему выбираются только случайно из `duel_tanks70 / duel_tanks80 / duel_tanks90`.

## Логи для следующего теста

Проверь строки:

- `[NEU-BOT] START v1.3`
- `[NEU-BOT] OPENING FLAG=`
- `[NEU-BOT] ARRIVED ... target=`
- `[NEU-BOT] INFANTRY PUSH`
- `[NEU-BOT] DETACHED squad=`
- `[NEU-BOT] TARGET FRONTIER`
- `[NEU-BOT] ATTACK flag=`

## Установка

Скопировать `bot.lua`, `bot.data.lua`, `bot.main.lua` из `BOT_GPT/v1_3/` в активный `script/multiplayer/` мода.

Версия v1.2 оставлена без изменений.
