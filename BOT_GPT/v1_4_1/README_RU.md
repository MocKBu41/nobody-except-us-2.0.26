# NEU BOT v1.4.1

Версия основана на v1.4 и исправляет выбор стартовой точки.

## Что было не так
В v1.4 BotApi не отдал координаты спавна (`SPAWN POSITION unavailable`), поэтому включался резервный выбор по номерам флагов и первая группа всегда получала `f1`.

## Что изменено
- Бот определяет свою сторону по `BotApi.Instance.team` / `enemyTeam`.
- Для Team A стартовые цели идут от малого номера: `f1 -> f2 -> f3...`.
- Для Team B стартовые цели идут от большого номера: `f11 -> f10 -> f9...` на карте 3vs3_country.
- Две стартовые штурмовые группы получают разные ближайшие точки со своей стороны.
- Разведка получает следующую свободную точку после целей штурмовых групп.
- Пехота, её БМП/БТР, отделившаяся пехота и назначенный танк сохраняют цель своей группы.
- Выбор танков остаётся только по тегам `duel_tanks70`, `duel_tanks80`, `duel_tanks90`.

## Новые строки лога
Проверять:
- `START v1.4.1`
- `TEAM SIDE team=... enemyTeam=... edge=HIGH/LOW`
- `TARGET SIDE flag=...`
- `GROUP CREATE id=1 target=...`
- `GROUP CREATE id=2 target=...`

Для теста USA/NATO на Team B ожидается примерно:
- Group 1 -> `f11`
- Group 2 -> `f10`
- Recon -> `f9`

Если движок показывает team в неожиданном формате, строка `TEAM SIDE` даст точное значение для следующей корректировки.
