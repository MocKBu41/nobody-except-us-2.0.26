# NEU BOT v1.5

Версия синхронизирована со схемой `bot-logic-editor (3).html` и сохраняет рабочую архитектуру v1.4.1.

## Старт
- 1 x `t(all recon)`.
- 2 x `t(all infantry)` — две независимые группы, каждая получает свою ближайшую по стороне стартовую точку.
- 1 x `t(all antiair)`.
- Через 5 секунд — 1 случайный танк с `duel_tanks70/80/90`.
- Team A идёт от младших номеров флагов, Team B — от старших. Для `3vs3_country`: A `f1 -> f2...`, B `f11 -> f10...`.

## Основная атака
Основная атака разблокируется:
1. через 5 минут; ИЛИ
2. раньше, если у врага флагов больше, чем у бота.

Группы атакуют разные цели. После начала атаки через 2 минуты проверяется результат:
- успех — атакующая пехота остаётся оборонять захваченную точку, затем для следующей атаки вызывается новый пехотный отряд;
- провал — вызывается `aircraftlight` на атакуемую точку и новый пехотный отряд для обороны ближайшего своего флага перед атакуемым.

## Танки
- стартовый танк: `duel_tanks70/80/90`;
- каждые 5 минут: новый `duel_tanks80/90`;
- при уничтожении танка: `duel_tanks80/90` + `all infantry` + `aat` + `aircraftlight`.
- `tank_usa` больше нигде не используется.

## Реакция на ПВО противника
При внешнем сигнале `NEU_BOT_EnemyTagSeen("aat")`:
- через 3 минуты `antirad`;
- ещё через 2 минуты проверка;
- если `aat` уничтожен -> `duel_heli`;
- если жив -> `antirad + strike`, затем повторная проверка через 2 минуты.

## Реакция на авиацию противника
При `NEU_BOT_EnemyTagSeen("aircraft")`:
- 50/50 вызывается `duel_fighter` или `aat`;
- через 2 минуты проверка;
- если самолёт уничтожен -> `duel_tanks80/90 + infantry`;
- если жив -> `duel_fighter`.

## Важное ограничение BotApi
В проверенном API нет подтверждённых `SplitSquad` и `Disembark`. Поэтому бот не пытается вызывать несуществующие команды. Если игра сама создаёт отдельные squad после высадки/разделения, v1.5 обнаруживает новые squad через `BotApi.Scene.Squads` и разносит их по разным незахваченным точкам.
