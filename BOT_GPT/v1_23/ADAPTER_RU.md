# Подключение к игре: обязательный внешний адаптер

В пакете НЕТ реализации команд GEM2 по координатам. Обычный BotApi и функция-заглушка NEU_EngineMove из предыдущей версии не предоставляют все необходимые возможности. Ни одна функция ниже не объявляется существующим методом игры.

Для выполнения, а не просмотра планов, интеграция игры должна создать глобальную таблицу NEU_TacticalAdapter до первого матча. Код вызывает её функции как обычные функции, без self:

- version = 1
- mapKey = точный ключ текущей карты из _flag_points_final.json. Должен совпадать с NEU_MAPDATA.mapKey. Совпадение названий f1/f2 не доказывает совпадения карт.
- getSquad(squadId) возвращает СВЕЖИЙ снимок либо nil. Снимок:
  {complete=true, kind="infantry"|"tank"|"ifv"|"other", position={x=...,y=...,z=...},
   spawn={x=...,y=...,z=...}, members={{id=...,alive=true,position={x=...,y=...,z=...}}, ...}}
  complete=true означает полный актуальный состав собственных бойцов, а не неполную видимость. Отсутствующий в полном составе прежний боец считается выбывшим. position для пехоты — актуальная опорная позиция отряда. spawn необязателен: только реальная точка появления этого отряда.
- validatePoint(squadId, unitId, point) -> true только для существующей, проходимой точки на ПРАВИЛЬНОЙ текущей карте; адаптер проверяет границы, поверхность, препятствия и допустимость позиции для типа юнита. point.z может отсутствовать; адаптер обязан определить высоту земли, не использовать выдуманный Z=0.
- moveSquad(squadId, point) -> true только после принятия команды движения. Команда заменяет прежний приказ CaptureFlag; движение рассчитывает движок с обходом препятствий.
- moveUnit(unitId, point) -> true после принятия независимой команды бойцу. Адаптер обязан обеспечить независимость от лидера/формации отряда и управление только собственными юнитами.
- holdSquad(squadId) и holdUnit(unitId) -> true после принятия устойчивого удержания позиции с возможностью огня. Должны отменять прежнее движение, преследование и восстановление старого группового приказа. Второй необязательный аргумент nil можно игнорировать.

nil, false, исключение = отсутствие подтверждения. Принятая команда НЕ означает прибытия.
getSquad должен прекращать выдавать снимки, если источник устарел; буфер старых координат не допускается.
Нельзя присваивать произвольный адрес из EXE этим функциям: сигнатуры и владение объектами должны быть проверены отдельно.

## Включение

1. Реализовать и проверить адаптер на локальном тестовом матче.
2. Подтвердить масштаб: измерить в игре известное расстояние и его разницу XY. UnitsPerMeter = расстояние XY / игровые метры.
3. В bot.tactics.config.lua задать UnitsPerMeter и Enabled=true.
4. Проверить правильность mapKey, классификацию БМП и полный состав пехоты.

По умолчанию Enabled=false, UnitsPerMeter=nil. Геометрия планов использует условный коэффициент 1 с явной меткой uncalibrated. Это НЕ утверждение, что единица GEM2 равна игровому метру.
Нет надёжного списка БМП: поэтому версия не определяет БМП по похожему имени юнита и не принимает экипаж/мотопехоту за пеший отряд. Классификация ifv берётся из адаптера.

## Границы реализации

Маршрут состоит из прямых геометрических участков. Обход препятствий выполняет движок через адаптер; формация и интервал 5,5 м задаются целевыми позициями. Непрерывное сохранение интервала при обходе зданий, столкновениях и боевых реакциях не гарантируется. Фронт ждёт прибытия всех оставшихся бойцов на очередную линию; застрявший боец задерживает продвижение, не считается прибывшим по таймеру.

Бойцы, добавленные в уже развёрнутый отряд, включаются при следующем построении маршрута.
Широкий фронт может не помещаться в круг захвата. Код не выдаёт финальный CaptureFlag, поскольку он свёл бы бойцов в одну точку; реальное занятие флага зависит от правил движка и числа бойцов в радиусе захвата.
