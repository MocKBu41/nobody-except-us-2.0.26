# NEU BOT v1.23 — маршруты и карта на базе v1.22

Основание: BOT_GPT/v1_22, commit 8a41db628d07183a1127f4a7cf8935de156585c1.
Статус: экспериментальный расчёт маршрутов + HTML-визуализация. Новые манёвры НЕ включены по умолчанию и НЕ выполняются без внешнего адаптера GEM2. Реальный бой не тестировался.

## Что добавлено

| Тип | Планируемое поведение |
|---|---|
| Пеший отряд | Подход к линии за 100 игровых метров от флага, расхождение влево/вправо, параллельное наступление с интервалом 5,5 м |
| Танк | Случайная позиция в радиусе 50–100 м от флага со стороны подхода |
| БМП | Случайная позиция в радиусе 20–50 м от флага со стороны подхода |
| Маршрут | Промежуточные точки с шагом 30 м; последний участок до обязательной точки может быть короче |
| Карта | Все живые отряды, доступные этому боту через Scene.Squads; отряды без координат остаются в списке |

Позиция техники сохраняется для текущего маршрута. Повторный приказ на тот же флаг не меняет случайное место. Новый маршрут на другой флаг получает новую позицию.
Пехота движется к линии развёртывания группой, затем отдельно по бойцам. Следующая линия фронта назначается после прибытия всех живых участников; выбывшие исключаются только по полному снимку адаптера.
Если начальная позиция уже ближе 100 м к флагу, построение начинается там, без отступления на 100 м.
Новый приказ на другой флаг перестраивает путь от текущей измеренной позиции. Старый путь не продолжается.

## Что доступно сразу, без адаптера

Исходная боевая логика v1.22 работает через свои прежние команды. Расширение записывает вычисленные планы в bot_routes_<hostId>.json каждые 3 игровые секунды. В отсутствие реальных координат начало плана — ориентир стороны из старого bot.mapdata.lua; это НЕ точный спавн каждого отряда. Количество бойцов в предварительном рисунке — 8, явно только предположение для визуализации.

Старое ограничение v1.22 сохранено: остановка танка через NEU_EngineMove тоже требует внешней реализации. Новая версия не устраняет эту зависимость и не сообщает, что танк выполнил рассчитанный план.

Из одного только CaptureFlag невозможно выполнить произвольные точки или раздать приказы отдельным бойцам. Для новых манёвров нужен адаптер из ADAPTER_RU.md, подтверждённая классификация техники, состав отряда, координаты и масштаб игровых метров.
При потере координат во время нового манёвра код запрашивает удержание и не переходит к следующей точке по времени.

## Установка

1. Скопировать все bot*.lua и оба JSON из этой папки в:
   mods/nobody except us 2.0.26/resource/script/multiplayer/
   с заменой файлов локальной копии мода.
2. Начать новый матч.
3. Открыть bot_visualizer.html двойным щелчком.
4. Выбрать bot_routes_<hostId>.json из script/multiplayer. Если запись туда недоступна, файл создаётся в рабочем каталоге игры.
5. Для нескольких ботов выбрать несколько файлов одной карты. «Следить за файлами» обновляет выбранные файлы раз в 3 секунды в браузере с File System Access API. Если кнопка недоступна — повторно выбирать обновлённый файл.
6. «Демонстрация» показывает отдельно помеченный пример с вымышленными данными.

В репозитории создана отдельная папка версии; рабочая script/multiplayer и v1_22 не изменены.

## Как читать карту

Пунктир — рассчитанный маршрут. Малые точки — плановые промежуточные приказы. Белая точка — последнее измеренное положение, только если адаптер его действительно вернул. Список справа показывает время измерения и источник спавна. Без измерений движущиеся маркеры не симулируются.
Метка «масштаб не подтверждён» означает условные единицы, а не измеренные игровые метры.
Карта — схема координат флагов и маршрутов, без изображения рельефа. Чужие армии, недоступные данному экземпляру бота, не отображаются.
Ползунок хранит последние 600 загруженных снимков. После очистки/перезапуска матча очистить старые снимки в просмотрщике.

## Изменения исходников

bot.v1_21.logic.lua: только три вызова расширения — сброс на старте, регистрация появления отряда, обновление раз в игровой тик. bot.v1_22.logic.lua, базовые core/support/data/mapdata и JSON скопированы из v1.22.
bot.lua и bot.main.lua подключают bot.tactics.lua, который загружает v1.22 и оборачивает N.capture.
Новые файлы: конфигурация, чистая геометрия, контроллер с экспортом, HTML-карта, описание адаптера и тест геометрии.

## Проверка

Синтаксис изменённых Lua-файлов проверен luaparse в режиме Lua 5.1. JavaScript просмотрщика проверен на синтаксис; импорт, демонстрация и фильтры проверяются с имитацией DOM, без настоящего браузера.
Тест tests/geometry.lua проверяет диапазоны остановки, масштабирование, шаг маршрута, стабильность позиций и интервал фронта. Команда из этой папки: lua tests/geometry.lua.
Запуска Lua и GEM2 в среде разработки нет: выполнение Lua-теста и поведения в игре пока не проверено.
