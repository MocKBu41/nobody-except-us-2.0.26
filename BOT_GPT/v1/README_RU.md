# NEU BOT v1

Основа: штатный `script/multiplayer/bot.lua` из Nobody Except Us 2.0.26, проверенные вызовы BotApi из предыдущей ветки BOT 2 и пользовательская схема `bot-logic.json`.

## Что реализовано

- Стартовая последовательность: `t(all recon)`, `t(all infantry)`, `t(all antiair)`, затем через 5 секунд `t(tank_usa)`.
- Юниты выбираются по токенам `t(...)`, а не по жёстко заданным именам техники.
- Разведка и пехота идут на флаг первыми, `tank_usa` получает тот же приказ через 5 секунд.
- ПВО (`all antiair` / `aat`) направляется по собственным флагам.
- Первая атака начинается через 5 минут либо раньше, если у противника больше флагов.
- Сначала выбирается нейтральный флаг, затем вражеский.
- Через 2 минуты после начала атаки проверяется захват цели:
  - если флаг захвачен — вызывается пехота на оборону этого флага;
  - если нет — вызываются `aircraftlight` на атакуемое направление и пехота на собственную линию обороны.
- Если после атаки у бота больше флагов, бот переходит в ожидание на 5 минут и обороняет свои точки.
- При потере собственного `tank_usa` вызывается новый `tank_usa` и дополнительная пехота.
- Реализованы ветви схемы для реакции на `aat` и `aircraft`: `antirad`, `strike`, `duel_heli`, `duel_fighter`, 50/50 fighter/aat.

## Важное ограничение v1

Проверенный Lua BotApi из штатного бота не даёт подтверждённого способа определить, что именно игрок вызвал юнит с тегом `aat` или `aircraft`, и не даёт подтверждённого события уничтожения конкретного вражеского тега. Поэтому эти ветви уже написаны, но ждут сенсорного хука.

Для подключения предусмотрены функции:

```lua
NEU_BOT_EnemyTagSeen("aat")
NEU_BOT_EnemyTagDestroyed("aat")
NEU_BOT_EnemyTagSeen("aircraft")
NEU_BOT_EnemyTagDestroyed("aircraft")
```

Как только будет найдено подтверждённое событие/поле движка для вражеских вызовов, его можно подключить к этим функциям без переписывания основной логики.

Принудительная высадка пехоты из транспорта пока не добавлена: в подтверждённом BotApi нет проверенной команды `Disembark/Unload`. Неизвестные методы намеренно не выдумывались.

## Установка для теста

1. Сделать резервную копию текущих `script/multiplayer/bot.lua`, `bot.data.lua`, `bot.main.lua`.
2. Скопировать три файла из `BOT_GPT/v1/` в `script/multiplayer/`.
3. Убедиться, что папка мода называется `nobody except us 2.0.26`, либо изменить `NEU_BOT.ModFolder` в `bot.data.lua`.
4. Папка `resource/set/multiplayer/units/` должна быть распакована, как и для штатного бота.
5. Запустить бой и искать в `game.log` строки с префиксом `[NEU-BOT]`.

## Что прислать после теста

Нужен `game.log` от момента `[NEU-BOT] START` до первых вызовов/захватов. По нему можно сразу сделать v1.1: исправить реальные отказы Spawn, подобрать доступные теги и подключить дополнительные события движка.
