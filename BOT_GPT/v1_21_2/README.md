# NEU BOT v1.21

Основание: v1.20, bf040f0c0f24177431b2c8e6f1d437fccb4651e0. Полный комплект; предыдущие версии не меняются.

## Установка

Скопировать bot*.lua и оба JSON этой папки в mods/nobody except us 2.0.26/resource/script/multiplayer/ с заменой. Начать новый матч. Загрузка: bot.main.lua (или bot.lua) → bot.v1_21.logic.lua → bot.v1_21.core.lua + bot.v1_21.support.lua. Старые модули не требуются.

## Рабочие изменения

- Каждые 30 секунд бот проверяет наличие зарегистрированного отряда antiair/aat. Если ни одного нет и покупка ещё не ожидается, заказывает замену. Предпочитает antiair, при отсутствии кандидатов использует aat. Неудачные покупки повторяются. Целевой минимум — один отряд ПВО на бота, как в прежнем открытии.
- Поддерживаются точные теги airbot и uavbot. Самолёты airbot при наличии кандидатов заменяют aircraftlight в обычной поддержке. При отсутствии airbot сохраняется aircraftlight. Пул юнитов читается из существующих файлов сторон, сами файлы юнитов не изменялись.
- Одиночные самолёты распределяются между действующими БТГ по времени последней полученной авиаподдержки. Сохраняется общий КД не меньше 360 секунд, включая отсчёт от фактического появления.
- Условная ветка при подтверждённом отсутствии ПВО: airbot либо пара uavbot (при доступности обоих вариантов выбор 50/50). Для пары нужны две активные БТГ и отсутствие действующей авиаподдержки; по одному БПЛА каждой группе. Пара занимает один общий цикл КД. Успешное появление каждого продлевает общий КД. Возможен частичный вызов, если движок не позволяет купить второй аппарат; повторные попытки ограничены настройками.
- Условная ветка при подтверждённом наличии AAT: через 180 секунд устойчивых свежих наблюдений запросить antirad. При наличии известного флага расположения отдаётся приказ на этот флаг; иначе — на цель БТГ. Это CaptureFlag, а не прямая команда уничтожить конкретную машину.

## Что пока НЕ работает автоматически

В текущем BotApi подтверждено только EnemyHasTanks. В логе Scene/Commands/Events имеют тип userdata, списка вражеских юнитов и координат нет. Поэтому штатная v1.21 не определяет наличие или отсутствие AAT и не активирует условные UAV/antirad-ветки самостоятельно.

Для будущего подтверждённого источника добавлена функция N.reportEnemyAA(present, flag, source): boolean, необязательный существующий флаг, непустое имя источника. False допускается только после полного достоверного сканирования армии, а не отсутствия видимого ПВО. Встроенного поставщика этих данных нет. Наблюдения старше 45 секунд становятся неизвестными; неизвестное не равно отсутствию. Перед каждой попыткой покупки условие перепроверяется, устаревшие/неподходящие заявки отменяются.

Если машина ПВО уничтожена, но её экипаж сохраняет squadId, IsSquadExists может оставаться true. Автозамена по исчезновению отряда этот случай НЕ исправляет. Подтверждённого чтения боеспособности конкретной машины сейчас нет; бот не покупает бесконечные дубликаты по выдуманному таймеру уничтожения.

В проверенных доступных units_usa, units_rus, units_nato, units_ukr, units_wagner.set в текущем GitHub тегов airbot/uavbot не найдено. Для реальных вызовов эти теги должны присутствовать у выбранных пользователем юнитов в локальных файлах мода. units_ch/units_nov по запрошенным путям не были доступны. Версия не назначает теги произвольным самолётам.

Lua 5.4 с имитацией BotApi: регрессии v1.20; замена ПВО и отсутствие дублирования; выбор airbot; запрет условных UAV при неизвестном ПВО; два UAV разным БТГ; отмена при появлении ПВО; задержка antirad; истечение разведданных; привязка UAV и общий КД.
