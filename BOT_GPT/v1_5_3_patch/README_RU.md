# NEU BOT v1.5.3 patch

Основа: рабочая v1.5.2. Этот патч исправляет только проблему, когда после захвата нейтральных точек одна из двух штурмовых групп остаётся в `opening`, поэтому реально атакует только второе направление.

## Что показал game.log

В логе было `G1=f11:opening G2=f7:attack` при `N=0`. То есть нейтральных точек уже не осталось, но первая группа так и не вышла из стартовой фазы. Поэтому в бой шёл только второй пехотный отряд, а танк оставался привязан к первой группе.

## Исправление

`bot.assault2.lua` запоминает два стартовых BMP+infantry отряда v1.5.2 и после выполнения условий атаки принудительно ведёт их на две разные вражеские точки.

Условия старта атаки:
- нейтральных флагов `N=0`;
- прошло 5 минут ИЛИ у противника больше флагов;
- оба стартовых штурмовых отряда существуют.

Каждые 5 секунд направления подтверждаются. Если один из двух штурмовых отрядов уничтожен, соответствующее направление останавливается, второе продолжает атаку.

Патч не перехватывает `BotApi.Commands`, не меняет спавн v1.5.2 и не трогает двухбойцовые группы захвата нейтральных флагов.

## Установка

Оставить `bot.lua` и `bot.data.lua` от `BOT_GPT/v1_5_2/`.

Скопировать:
- `BOT_GPT/v1_5_3_patch/bot.assault2.lua` -> `script/multiplayer/bot.assault2.lua`
- `BOT_GPT/v1_5_3_patch/bot.main.lua` -> `script/multiplayer/bot.main.lua`

## Строки проверки в game.log

```text
[NEU-153] START v1.5.3 patch two-direction=ON
[NEU-153] TRACK assault1 squad=...
[NEU-153] TRACK assault2 squad=...
[NEU-153] TWO-DIRECTION ATTACK ENABLED ...
[NEU-153] ASSAULT slot=1 ... flag=...
[NEU-153] ASSAULT slot=2 ... flag=...
```

Цели slot=1 и slot=2 должны быть разными.
