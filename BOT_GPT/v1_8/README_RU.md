# NEU BOT v1.8 — геометрия карты

Версия 1.8 добавляет слой знания карты. Бот больше не должен считать, что `f1/f2/...` автоматически означают порядок от своего края карты.

## Основа логики

Сохранены правила редактора логики: сначала все нейтральные точки, затем атака игрока; 2 независимые БТГ; `recon` захватывает точки; для быстрого захвата нейтралов вызываются пары `vehicle_supporter` (если тег найден), размер группы 2; ПВО держится на своих передовых точках; атака открывается через 5 минут или при преимуществе противника по флагам; результат атаки проверяется через 2 минуты; потеря танка не закрывает направление; при потере основной штурмовой пехоты направление временно прекращается и восстанавливается.

## Что изменилось в v1.8

`bot.mapdata.lua` читает `_flag_points_final.json`, определяет текущую карту по набору живых `BotApi.Scene.Flags` и строит таблицу координат флагов.

Если рядом лежит `_map_points_index.json`, из точек `a*` / `b*` вычисляется медианная точка спавна своей команды. Для текущей тестовой карты `3vs3/3vs3_country` добавлен встроенный запасной A/B anchor на случай, если index-файл отсутствует.

На основе геометрии:

- `recon` получает ближайший свободный нейтральный флаг относительно своего спавна;
- до 3 групп захвата по 2 бойца получают следующие ближайшие свободные нейтралы;
- после захвата всех нейтралов БТГ выбирают разные вражеские цели;
- передовой свой флаг определяется по реальному расстоянию до вражеских флагов;
- fallback-оборона выбирает свой флаг, геометрически ближайший к атакуемой точке и находящийся ближе к своей стороне;
- ПВО и дополнительная оборона используют геометрически передовые свои флаги.

## Установка для теста

В `resource/script/multiplayer/` мода положить:

1. `bot.lua`
2. `bot.data.lua`
3. `bot.main.lua`
4. `bot.mapdata.lua`
5. `_flag_points_final.json` — обязательно для геометрии флагов
6. `_map_points_index.json` — желательно для определения координаты спавна на всех поддерживаемых картах

Если JSON не найден или карта не определяется однозначно, бот продолжит работать, но выбор целей откатится к числовому fallback; это будет видно в логе.

## Ограничение 100 м для танка

Координаты флагов теперь известны, но проверенной команды BotApi для перемещения отряда в произвольную координату (`Move/Stop`) всё ещё нет. Поэтому точную позицию танка в 100 игровых метрах от флага v1.8 не выдумывает. Для этого нужен реально существующий API/скриптовый вызов движения.

## Важно

Версия создаётся отдельным снимком `BOT_GPT/v1_8/`. Старые версии не перезаписываются.
