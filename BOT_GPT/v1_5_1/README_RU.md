# NEU BOT v1.5.1

Основа: рабочая версия `BOT_GPT/v1_5`.

В этой версии не используются `bot.guard.lua`, перехваты `BotApi.Commands` или отдельные диагностические модули. Логика встроена непосредственно в рабочее ядро v1.5.

## Добавлено по схеме bot-logic-editor (4)(1).html

- Старт: 1 `t(all recon)`, 2 пехотных группы `t(all infantry)`, 1 `t(all antiair)`, танк через 5 секунд из `duel_tanks70/80/90`.
- Две независимые штурмовые группы продолжают работать раздельно.
- Строгое правило: пока есть нейтральные точки, бот выбирает только нейтральные. Вражеские флаги становятся целями только после захвата всех нейтральных.
- Разведка и обнаруженные отдельные/спешенные отряды тоже сначала распределяются по свободным нейтральным точкам.
- Атака открывается через 5 минут или если у противника больше флагов, как в v1.5.
- Проверка результата атаки через 2 минуты: успех -> пехота остаётся оборонять; неудача -> `aircraftlight` + оборонительная пехота на своей точке перед атакуемой.
- Каждые 5 минут вызывается новый `duel_tanks80/90`.
- При уничтожении танка вызываются: `duel_tanks80/90`, пехота, случайный `aat`, `aircraftlight`.
- Если штурмовая группа теряет боевую единицу во время атаки на вражескую точку, направление этой группы помечается `stopped` и больше не продолжает атаку. Подкрепление танка перенаправляется в оставшееся активное направление.
- Ветка `aat`: через 3 минуты `antirad`, затем проверка через 2 минуты; уничтожен -> `duel_heli`, жив -> `antirad` + `strike` с повторной проверкой.
- Ветка `aircraft`: 50/50 `duel_fighter` или `aat`; через 2 минуты: уничтожен -> танк + пехота, жив -> `duel_fighter`.

## Ограничения подтверждённого BotApi

В доступном BotApi пока не подтверждены команды `SplitSquad`, `Disembark` и свободное перемещение по координатам. Поэтому v1.5.1 не подделывает их.

Если игра сама создаёт отдельный squad после спешивания/разделения, код v1.5.1 обнаруживает такой squad через `BotApi.Scene.Squads` и отправляет его на отдельную свободную точку.

Правило "танк остаётся в 100 игровых метрах от точки" пока не реализовано: для этого нужна подтверждённая команда движения/координаты, а не `CaptureFlag`, который ведёт технику прямо к точке.

## Установка

Скопировать из этой папки в `script/multiplayer/`:

- `bot.lua`
- `bot.data.lua`
- `bot.main.lua`

Не добавлять `bot.guard.lua` и `bot.probe.lua` из экспериментальных v1.6.

В логе рабочий запуск этой версии начинается строкой:

`[NEU-BOT] START v1.5.1 ...`

и затем:

`[NEU-BOT] RULE neutral-first=ON direction-stop=ON split/dismount=runtime-only`
