# NEU BOT v1.7

Полноценная отдельная версия на базе рабочей логики v1.5/v1.5.2. `v1.6`, `bot.guard.lua`, `bot.probe.lua` и отдельный `v1.5.3 patch` не используются.

## Что исправлено по последнему game.log и шаблону поведения

### 1. Две БТГ работают независимо

Создаются две группы. Каждая получает собственный `t(all infantry)` и собственный танк из `duel_tanks70/80/90` через 5 секунд.

После окончания нейтральной фазы обе группы принудительно переводятся в `ready`, даже если их старый стартовый флаг был потерян или захвачен другой стороной. Состояние `G1=...:opening` при `N=0` больше не должно блокировать первую группу.

При начале атаки группы получают разные вражеские флаги. Если свободных вражеских флагов меньше двух, вторая группа ждёт отдельную цель, а не идёт на тот же флаг.

### 2. Строгий neutral-first

Пока существует хотя бы один нейтральный флаг, основные БТГ не атакуют вражеские точки.

Нейтральные флаги получают только специальные `capture_infantry` группы с `MaxSquadSize=2`. Разведка, ПВО и танки не получают приказ `CaptureFlag` на нейтральную точку.

После `N=0` в логе должно быть:

```text
[NEU-BOT] NEUTRALS CLEARED ... force-all-groups-ready=YES
[NEU-BOT] GROUP READY id=1 ...
[NEU-BOT] GROUP READY id=2 ...
```

### 3. vehicle_supporter

Код сначала ищет среди доступных multiplayer-unit записей кандидатов, где встречается `vehicle_supporter`, и если такие записи найдены, использует их для двухбойцовых захватчиков.

Если `vehicle_supporter` существует только как breed/роль бойца внутри уже вызванного отделения, а не как отдельная запись units*.set, BotApi не даёт проверенной команды `SplitSquad` для выбора двух конкретных бойцов. Поэтому используется безопасный fallback: `t(all infantry)` с `MaxSquadSize=2`.

В логе видно режим:

```text
[NEU-BOT] CAPTURE SOURCE=vehicle_supporter
```

или

```text
[NEU-BOT] CAPTURE SOURCE=all infantry fallback
```

### 4. Потеря направления

Если во время атаки вражеской точки уничтожается основная пехота или танк БТГ, это направление переводится в `stopped`. Вторая БТГ продолжает действовать.

```text
[NEU-BOT] DIRECTION STOP group=1 ...
```

Танк при уничтожении всё ещё запускает реакцию шаблона: новый `duel_tanks80/90`, пехота, `aat` и `aircraftlight`; подкрепление назначается оставшейся активной группе.

### 5. Поведение после захвата точки

Через 2 минуты проверяется результат атаки.

- Успех: текущая пехота остаётся оборонять захваченный флаг, группа через 5 секунд ищет следующую отдельную вражескую цель и получает новую штурмовую пехоту.
- Неудача: вызывается `aircraftlight` и отдельная `defense_infantry` на свою передовую точку; через 2 минуты проверка повторяется.

### 6. Подкрепления каждые 5 минут

Каждая активная БТГ получает:

- `duel_tanks80/90`;
- новый `t(all infantry)`.

Если нейтралы ещё существуют, пехотное подкрепление поддерживает механизм захвата нейтральных точек вместо преждевременной атаки врага.

### 7. Оборона при преимуществе по флагам

Когда у бота становится больше флагов, чем у игрока, для активных групп вызывается по отделению `defense_infantry` на наиболее передовые собственные точки.

### 8. ПВО и специальные реакции

Сохранены:

- `t(all antiair)` на своих передовых точках;
- enemy `aat` -> через 3 минуты `antirad` -> проверка 2 минуты -> `duel_heli` либо `antirad + strike`;
- enemy `aircraft` -> 50/50 `duel_fighter` или `aat`, затем повторная реакция;
- исключение `nobot`;
- случайный выбор танков из `duel_tanks70/80/90`, для подкреплений `duel_tanks80/90`.

## Ограничение 100 метров для танка

В шаблоне танк должен находиться примерно в 100 игровых метрах от точки. Это единственная часть, которая пока не может быть реализована точно через подтверждённый BotApi: у нас по-прежнему нет проверенной команды `Move`/`Stop` по координатам и доступных координат флага.

v1.7 не выдумывает несуществующую команду. Танк входит в соответствующую БТГ и начинает движение к её цели с задержкой 5 секунд через проверенный `CaptureFlag`. Для настоящего standoff 100 м нужен найденный API движения/координат либо данные карты.

## Проверка версии

При запуске:

```text
[NEU-BOT] START v1.7 ...
[NEU-BOT] RULE two-BTG=ON strict-neutral-first=ON ...
```

После нейтралов и открытия атаки ожидается примерно:

```text
NEUTRALS CLEARED ...
ATTACK START group=1 flag=fX ...
ATTACK START group=2 flag=fY ...
```

`fX` и `fY` должны быть разными.

Статус раз в 30 секунд:

```text
TIME=... FLAGS=... N=... CAP2=... GROUPS G1=fX:attack:I1:T1 G2=fY:attack:I1:T1
```

## Установка

Из `BOT_GPT/v1_7/` скопировать в `script/multiplayer/` только:

- `bot.lua`
- `bot.data.lua`
- `bot.main.lua`

Удалить/не подключать старые `bot.guard.lua`, `bot.probe.lua`, `bot.assault2.lua`.
