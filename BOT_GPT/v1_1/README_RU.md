# NEU BOT v1.1

Исправления по game.log:

- Удалена роль `tank_usa`.
- Роль `tank` выбирается случайно среди доступных юнитов с одним из тегов:
  - `duel_tanks70`
  - `duel_tanks80`
  - `duel_tanks90`
- Юниты с `nobot` по-прежнему не вызываются ботом.
- В лог добавлена строка `TANK RANDOM unit=... tags=...`, чтобы было видно, какой именно танк выбран.
- После захвата текущего флага бот больше не ждёт окончания 120-секундной проверки: он сразу выбирает следующую незахваченную точку и выдаёт новые `CaptureFlag`.
- В лог добавлены `ORDER squad=... flag=... role=...` для проверки приказов.

По предыдущему game.log было подтверждено, что `CaptureFlag` сам по себе работает: бот атаковал `f10`, движок получил команды CaptureFlag и флаг был захвачен. Главная проблема была в отсутствии кандидатов `tank_usa` и в задержке перехода на следующую точку.

## Установка

Скопировать `bot.lua`, `bot.data.lua`, `bot.main.lua` из этой папки в `script/multiplayer/` мода с заменой файлов.

После теста искать в game.log:

- `[NEU-BOT] ROLE tank candidates=` — должно быть больше 0;
- `[NEU-BOT] TANK RANDOM unit=` — выбранный случайный танк;
- `[NEU-BOT] SPAWN OK role=tank`;
- `[NEU-BOT] ATTACK flag=`;
- `[NEU-BOT] ORDER squad=`;
- `[NEU-BOT] ATTACK SUCCESS flag=... -> NEXT FLAG`.
