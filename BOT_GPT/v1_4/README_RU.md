# NEU BOT v1.4

Версия сделана по результатам `game — копия (4).log`.

## Что исправлено

В v1.3 все пехотные и отделившиеся отряды регулярно получали один глобальный `CurrentAttackFlag`, поэтому вся армия стягивалась на одну точку.

В v1.4 введены самостоятельные боевые группы.

Каждая группа хранит собственную цель:

- пехотный отряд с его БМП/БТР;
- отделившаяся после спешивания пехота;
- назначенный этой группе танк.

Повторный приказ каждые 5 секунд теперь идёт на `group.target`, а не на общую цель всей армии.

## Старт боя

1. Сначала вызывается разведка.
2. Бот пытается безопасно получить координаты точки появления через доступные поля объектов BotApi (`position`, `pos`, `point`, `x/y/z`).
3. Если координаты доступны, стартовые группы получают ближайшие к спавну разные точки по реальной геометрической дистанции.
4. Если эта сборка игры не отдаёт координаты в BotApi, бот не ломается и включает резервное разнесение целей по фронту.
5. Стартуют две штурмовые группы пехоты с разными целями.
6. Первый танк через 5 секунд прикрепляется к первой группе. Последующие танки распределяются по группам с наименьшим числом танков.
7. Разведка получает отдельную точку, не занятую текущими штурмовыми группами.

## После захвата

Когда группа захватила свою точку, она самостоятельно выбирает следующую свободную цель и продолжает наступление. Цели других активных групп исключаются из выбора, чтобы группы не слипались.

## Полезные строки лога

- `[NEU-BOT] START v1.4`
- `[NEU-BOT] SPAWN POSITION ...`
- `[NEU-BOT] SPAWN POSITION unavailable -> fallback target spread`
- `[NEU-BOT] TARGET GEOMETRY flag=...`
- `[NEU-BOT] GROUP CREATE id=... target=...`
- `[NEU-BOT] ORDER squad=... group=... flag=...`
- `[NEU-BOT] DETACHED squad=... group=... target=...`
- `[NEU-BOT] GROUP PUSH id=...`
- `[NEU-BOT] GROUP CAPTURE id=...`
- `[NEU-BOT] GROUP NEXT id=...`
- `[NEU-BOT] TIME=... GROUPS G1=... G2=...`

## Установка

Скопировать из `BOT_GPT/v1_4/` в активный каталог мода `script/multiplayer/`:

- `bot.lua`
- `bot.data.lua`
- `bot.main.lua`
