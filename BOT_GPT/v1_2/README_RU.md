# NEU BOT v1.2

Версия сделана по новой HTML-схеме логики `bot-logic-editor (2).html` с сохранением последнего уточнения: никакого `tank_usa`.

## Старт

- 1 юнит `t(all recon)` — последовательно объезжает нейтральные/вражеские флаги и после захвата текущего получает следующий.
- 2 отряда `t(all infantry)`.
- 1 юнит `t(all antiair)` — каждые 20 секунд получает новый свой флаг для патрулирования.
- через 5 секунд вызывается случайный танк из юнитов с одним из тегов:
  - `duel_tanks70`
  - `duel_tanks80`
  - `duel_tanks90`

## Танки

- При уничтожении собственного танкового отряда: новый случайный танк + пехота.
- Если танк не уничтожен, каждые 5 минут добавляется ещё один случайный танк.
- При атаке танк получает ту же точку, что пехота, с задержкой 5 секунд.

## Захват точек

- Основная атака начинается через 5 минут или раньше, если у противника больше флагов.
- Цель: сначала нейтральный флаг, затем вражеский.
- Через 2 минуты проверяется результат.
- Если флаг захвачен — вызывается пехота на оборону этого флага.
- Если флаг не захвачен — вызывается `t(aircraftlight)` на атакуемую точку и пехота на ближайшую свою линию обороны.
- После результата сравнивается баланс флагов:
  - у бота преимущество — оборона/ожидание 5 минут;
  - преимущества нет — новая атака через короткую задержку.

## Ветка AAT

- обнаружен вражеский `t(aat)`;
- через 3 минуты `t(antirad)`;
- через 2 минуты проверка уничтожения;
- уничтожен -> `t(duel_heli)`;
- выжил -> `t(antirad)` + `t(strike)`, затем повтор проверки.

## Ветка aircraft

- обнаружен вражеский `t(aircraft)`;
- 50/50: `t(duel_fighter)` или `t(aat)`;
- если авиация уничтожена -> случайный танк `duel_tanks70/80/90` + пехота;
- если выжила -> `t(duel_fighter)`.

## Ограничение API

В новой схеме есть два действия, для которых в проверенной `BotApi.Commands` пока не найден реальный метод:

1. разбить один отряд на несколько самостоятельных групп;
2. принудительно высадить пехоту из транспорта на половине пути.

Поэтому v1.2 не вызывает выдуманные `SplitSquad`/`Disembark`. Разведка реализована одним отрядом, который последовательно захватывает точки. Для высадки в логе выводится `DISEMBARK PENDING`; её подключим после нахождения реальной команды движка.

## Установка

Скопировать `bot.lua`, `bot.data.lua`, `bot.main.lua` из `BOT_GPT/v1_2/` в активный `script/multiplayer/` мода.

Для теста полезны строки лога:

- `[NEU-BOT] START v1.2`
- `[NEU-BOT] ROLE tank candidates=`
- `[NEU-BOT] TANK RANDOM`
- `[NEU-BOT] RECON NEXT`
- `[NEU-BOT] AA PATROL`
- `[NEU-BOT] ATTACK flag=`
- `[NEU-BOT] ATTACK SUCCESS`
- `[NEU-BOT] ATTACK STALLED`
- `[NEU-BOT] BALANCE`
