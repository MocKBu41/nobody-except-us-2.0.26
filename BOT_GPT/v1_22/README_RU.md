# NEU BOT v1.22 — TANK STANDOFF TEST

Снапшот текущей тестовой версии v1.22.

## Главное изменение

В фазе штурма танк больше не должен получать центр флага как конечную позицию.
Позиция рассчитывается по линии от собственного респавна к целевому флагу:

`T = F - normalize(F - S) * D`

где `S` — координаты собственного spawn anchor, `F` — координаты флага, `D` — стабильное для squad расстояние 60–70 метров.

Пехота продолжает получать обычный CaptureFlag и заходит непосредственно на точку.

## Важно для теста

Штатный BotApi использует CaptureFlag и не даёт проверенной произвольной команды Move(x,y). Поэтому v1.22 ожидает низкоуровневый мост `NEU_EngineMove(squadId, x, y, z)`. Пока мост не подключён, танк НЕ получает fallback CaptureFlag на атакуемый флаг: он удерживает предыдущую позицию, а в game.log выводится `TANK STANDOFF REQUEST ... BRIDGE=WAIT` с рассчитанными координатами.

Снапшот сохраняет зависимости v1.21, на которых построена v1.22.
