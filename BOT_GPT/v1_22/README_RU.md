# NEU BOT v1.22 — тактика + живая карта

Версия собрана поверх проверенной логики v1.21 и использует наработки визуализации v1.20/v1.21.

## Тактика штурма

- Каждый штурмовой отряд получает полный план движения от собственного `SPAWN` с контрольными точками через **30 игровых метров**.
- Пехота выходит на рубеж **100 м** от атакуемой точки, после чего планируется фронт бойцов с интервалом **5.5 м** и движение к точке.
- Танк получает устойчивую случайную позицию в диапазоне **50–100 м** от точки с боковым смещением и не получает fallback-команду въехать в центр флага.
- БМП/транспорт пехоты получает отдельную позицию поддержки **20–50 м** от точки.
- Для каждого squad сохраняется `NEU22Plans`: маршрут, цель, точки через 30 м, маршрут БМП и линии пехотинцев.

Точное перемещение по произвольным координатам использует низкоуровневые мосты `NEU_EngineMove`, `NEU_EngineMoveCarrier`, `NEU_EngineMoveMember`, если они доступны. Без них бот продолжает использовать безопасные штатные команды v1.21 там, где это возможно, а рассчитанный тактический план всё равно попадает в телеметрию.

## Авиация

БПЛА полностью исключены из вызова поддержки. Роли `airbot` и `uavbot` блокируются даже при попытке старого кода поставить их в очередь.

Используются только явные авиационные роли:

- `strike`;
- `aircraftlight`;
- `antirad` при подтверждённой ПВО противника.

Это сделано потому, что в предыдущих логах пул `airbot` содержал одновременно самолёты и Bayraktar.

## Визуализация

Используй **`bot_visualizer.html`** — это основной визуализатор v1.22 в стиле старых версий бота.

Бот пишет файл `bot_gpt_telemetry.jsonl`. Визуализатор показывает:

- реальные точки карты и их принадлежность;
- `SPAWN`;
- направления атак групп;
- полный маршрут каждого squad через 30 м;
- рубеж развёртывания пехоты;
- линии отдельных бойцов;
- маршрут/позицию БМП;
- последнюю координатную команду;
- реальное положение squad только тогда, когда подключён `NEU_TacticalAdapter.getSquad()` и бот действительно получает координаты из игры;
- события, решения, вызовы и потери по времени.

Для обычного просмотра нажми **«Открыть telemetry JSONL»**. Для обновления карты во время боя в Chromium-браузере нажми **«Live-файл»** и выбери текущий `bot_gpt_telemetry.jsonl`.

`movement_visualizer.html` оставлен как упрощённый диагностический просмотр строк `MOVEPOINT/MEMBERPOINT`; основной файл для испытаний — `bot_visualizer.html`.

## Что искать в game.log после теста

- `v1.22 TACTICS ACTIVE`
- `ROUTE PLAN squad=... step=30`
- `MOVEPOINT ...`
- `MEMBERPOINT ... spacing=5.5`
- `AIR BLOCK DRONE ROLE` — если какой-либо старый код попробовал вызвать БПЛА
- `AIRCRAFT ARRIVED ...` — успешный вызов самолёта
- `TELEMETRY v1.22 ACTIVE ...`
