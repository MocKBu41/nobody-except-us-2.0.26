# NEU BOT v1.0.0 — baseline

Эта папка является зафиксированным исходным снимком версии **1.0.0** по архиву `multiplayer.rar`, предоставленному пользователем 2026-09-16.

## Правило

Файлы `v1_0_0` считать эталонной исходной версией и не переписывать при разработке следующих версий. Новые изменения делать копированием этой версии/последнего проверенного снимка в новую папку версии.

## Состав исходного архива

- `multiplayer/bot.data.lua`
- `multiplayer/bot.lua`
- `multiplayer/bot.main.lua`
- `multiplayer/scan_bot_commands.py`

Код перенесён как содержимое предоставленного архива, без исправления логики. В частности, строка `mod_folder_name = "nobody except us 2.0.25"` в `bot.data.lua` намеренно сохранена как в исходнике.
