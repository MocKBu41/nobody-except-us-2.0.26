# NEU BOT v1.27

Новая отдельная версия. v1.26 не изменяется.

## Что изменено

- `bot_visualizer.html` перерисовывается через `requestAnimationFrame` с целевой частотой 60 FPS.
- Карта стала контрастнее: атакующие направления выделены яркими оранжевыми коридорами, цель атаки пульсирует жёлтым.
- Для каждого отряда бота при приказе на точку строится маршрут с узлами через 30 игровых метров (`ROUTE30`, `WAYPOINT30`).
- Телеметрия v1.27 сохраняет `route` для каждого squad, поэтому визуализатор показывает не только группы атаки, но и маршруты pointstart, пехоты, танков, ПВО, разведки и поддержки, когда им назначена точка.
- Пехотные маршруты имеют escort-маршрут БТР. На визуализации БТР использует тот же темп, что и пехота, и держится позади на `CarrierEscortLeashMeters` (по умолчанию 15 м).
- Белая метка `[ФАКТ]` используется только для позиции, реально полученной через `NEU_TacticalAdapter`. Голубая `[ПЛАН]` — интерполированное положение по приказу/маршруту.

## Важно про движение в самой игре

В проверенном BotApi этой сборки подтверждён `CaptureFlag`, но не найден штатный вызов произвольного `MoveTo(x,y)` для squad. Поэтому v1.27 не подменяет рабочий игровой приказ выдуманной командой: физическое движение продолжает выполняться через проверенный `CaptureFlag`, а 30-метровые точки используются как тактический маршрут и телеметрия. Старые внешние `NEU_EngineMove*` bridge-функции по-прежнему могут использоваться более низким слоем, если они появятся.
