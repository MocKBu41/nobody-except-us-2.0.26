# NEU BOT v1.5.2

Основа: рабочая ветка v1.5 / v1.5.1. Версии v1.6 не используются.

## Что исправлено по game.log

В логе v1.5.1 на TIME=300 оставалось `N=2`, но одна группа уже была в `attack`, а каждые 5 минут вызывался только новый танк. Поэтому бот мог начать атаку врага до полного захвата нейтральных точек и после ~5 минут не получать новую пехоту, если не срабатывало событие потери/неудачной атаки.

## Новая логика нейтральных точек

- Нейтральные флаги может получать приказ `CaptureFlag` только роль `capture_infantry`.
- Для `capture_infantry` используется `BotApi.Commands:Spawn(unit, 2)`, то есть `MaxSquadSize=2` именно для захватчиков.
- На каждую свободную нейтральную точку создаётся отдельная пара захватчиков.
- Если пара уничтожена, точка снова становится кандидатом и вызывается новая пара.
- Пока есть хотя бы одна нейтральная точка, обычные штурмовые группы не начинают атаку вражеских флагов.
- Если нейтральная точка появляется снова во время атаки, атака ставится на паузу до зачистки нейтралей.
- Разведка, танки и ПВО больше не получают приказ захвата нейтрального флага.

Важно: это не `SplitSquad` существующего отряда. Проверенной команды для выбора ровно двух конкретных бойцов внутри уже созданного squad в BotApi пока нет. Поэтому безопасная реализация использует проверенный параметр `MaxSquadSize=2` при отдельном вызове пехотного захватчика.

## Пехота после 5 минут

Добавлен `InfantryReinforcementSec = 300`.

- Если нейтральные точки ещё есть, пятиминутное подкрепление направляется на поддержку механизма захвата нейтралей.
- Если нейтралей нет, каждая активная штурмовая группа получает новый `t(all infantry)` раз в 5 минут.

## Проверка в логе

При запуске должны быть строки:

```
[NEU-BOT] START v1.5.2
[NEU-BOT] RULE neutral-only-capture_infantry=ON capture-pair-size=2 strict-neutral-first=ON infantry-5min=ON
```

Для двухбойцовых захватчиков:

```
[NEU-BOT] QUEUE role=capture_infantry ... target=fX
[NEU-BOT] SPAWN OK role=capture_infantry ... maxSquad=2
[NEU-BOT] ORDER ... role=capture_infantry flag=fX
```

Обычная техника на нейтральную точку должна блокироваться строкой:

```
[NEU-BOT] BLOCK NEUTRAL NONCAPTURE ...
```

Статус каждые 30 секунд:

```
TIME=... FLAGS=... N=... CAP2=...
```

`N` — число нейтральных флагов, `CAP2` — число живых двухбойцовых групп, которые сейчас назначены на нейтральные точки.

## Установка

Скопировать из `BOT_GPT/v1_5_2/` в `script/multiplayer/`:

- `bot.lua`
- `bot.data.lua`
- `bot.main.lua`

Не подключать `bot.guard.lua` и `bot.probe.lua` из v1.6.
