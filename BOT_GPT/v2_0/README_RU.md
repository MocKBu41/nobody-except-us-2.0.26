# NEU BOT 2.0 — УСТАРЕЛО / ОШИБКА

Первый игровой тест сохранён в `LOG/game_bot 2.0.log`.

Причина бездействия подтверждена: Lua-модули `bot.lua`, `bot.core.lua`, `bot.logic.lua` загружались, но в `bot.logic.lua` отсутствовали обязательные подписки `BotApi.Events:Subscribe(...)` на `GameStart`, `GameEnd`, `Quant`, `GameSpawn`. Поэтому функции жизненного цикла были объявлены, но движок их не вызывал.

Также пакет 2.0 был неполным: из него исчезли визуализатор и координатные наборы карт/SpawnPoint.

Эту папку сохраняем только как историю неудачного теста. Не использовать её как актуальную версию.

Исправление: `BOT_GPT/v2_0_1/`.
