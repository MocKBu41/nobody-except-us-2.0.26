# NEU BOT 2.0

Статус: **НУЖЕН ТЕСТ В ИГРЕ**.

Основа версии:
- `BOT_GPT/v1_30_1`: защита от unmatched/passenger squads, компактная телеметрия, безопасная очередь spawn и отказ от недостоверной геометрии карты;
- `COLDWAR-MOD-/BOT 2/v3_3_MULTI_FLAGS`: состояния OPENING / EXPAND / DEFEND / WAIT_REINFORCEMENT, разные цели для отрядов, пехота идёт раньше техники;
- `COLDWAR-MOD-/BOT 2/v3_RULES`: внутренняя экономика и таймеры;
- `BOT_MEMORY/BOT_LOGIC_CURRENT.json`: каноническая логика, присланная пользователем 2026-09-14.

## Что делает 2.0

1. OPENING последовательно вызывает infantry -> recon -> tank -> mech_inf.
2. Внутренняя экономика: 1200 BP, +20 BP/сек, резерв 200 BP.
3. Spawn retry каждые 2 сек, timeout 60 сек, перебор доступных кандидатов роли.
4. После OPENING -> EXPAND.
5. В EXPAND живые отряды распределяются по разным незахваченным флагам: выбирается флаг с минимальным числом уже назначенных живых отрядов; при равной нагрузке нейтральный флаг приоритетнее, затем используется стабильный порядок имени флага.
6. infantry и mech_inf получают приказы раньше tank/recon/attack_heli.
7. tank/recon/attack_heli следуют с задержкой 10 сек.
8. При потере recon/tank/mech_inf/attack_heli -> WAIT_REINFORCEMENT, очередь замены может тратить резерв, затем возврат к стратегическому состоянию.
9. Если преимущество по флагам >= 1 -> DEFEND. При потере преимущества -> EXPAND.
10. Если обычной infantry нет -> автодокупка infantry.
11. Attack helicopter вызывается только если подтверждён точный счётчик танков противника >= 3. Без счётчика -> HELI BLOCKED.
12. Unmatched squads игнорируются, чтобы пассажиры/экипажи не превращались в боевые отряды бота.
13. Телеметрия компактная: события + snapshot раз в 15 сек, лимит 2.3 MB на команду.

## Пока сознательно НЕ включено

- Координатная геометрия карты и tank standoff 50-100 м: v1.27 показал ошибочное определение карты только по именам `f1..f11`. Возвращать X/Y в решения нельзя до надёжного runtime map id.
- Развёртывание пехоты фронтом 5-6 м и остановка БМП 20-50 м: нужны достоверные runtime координаты и проверенный coordinate bridge.
- Высадка десанта: `crew_emit` найден, но безопасный BotApi/Lua метод выгрузки только десанта не подтверждён.
- Артиллерия отключена по текущей логике.

## Установка для теста

В рабочей папке мода файлы версии должны оказаться как:
- `resource/script/multiplayer/bot.lua`
- `resource/script/multiplayer/bot.core.lua`
- `resource/script/multiplayer/bot.logic.lua`

После боя сохранить `game.log` и `bot_gpt_telemetry_<team>.jsonl` в `/LOG/` репозитория. После подтверждения результат заносится в `GITHUB_MEMORY.md`.
