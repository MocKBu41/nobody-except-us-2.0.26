# GitHub Memory — NEU / GEM2 MoWAS2

Этот файл — постоянная проектная память репозитория `nobody-except-us-2.0.26`.

## Правило работы

Перед новой задачей по NEU / GEM2 MoWAS2 сначала прочитать этот файл и учитывать сохранённый статус, проверенные решения, ошибки и результаты испытаний. После существенного проверенного изменения дополнять память, а не начинать проект заново.

Основная локальная рабочая копия пользователя: `D:\GPT_NEU`. При наличии доступа к локальной файловой системе рабочие версии и вспомогательные результаты можно сохранять туда в соответствующие папки проекта.

## Текущие точки входа бота

- `script/multiplayer/bot.lua` -> `bot.v1_21.logic`
- `script/multiplayer/bot.main.lua` -> `bot.v1_22.logic`
- `v1.22` накладывается поверх `v1.21` и содержит эксперимент остановки танка перед точкой. Для движения в произвольные координаты ожидает необязательный низкоуровневый мост `NEU_EngineMove`.

## 2026-09-15 — Command Probe 1.0

Добавлена диагностика доступных боту команд GEM2/MoWAS2.

Файлы:

- `script/multiplayer/bot.command_probe.lua`
- `tools/scan_bot_commands.py`
- `BOT_COMMAND_PROBE.md`

Обе точки входа (`bot.lua` и `bot.main.lua`) безопасно пытаются загрузить probe через `pcall`. Ошибка probe не должна останавливать основную логику бота.

Runtime probe:

- перечисляет доступные члены `BotApi`, `BotApi.Commands`, `BotApi.Scene`, `BotApi.Instance` и доступных metatable;
- ищет интересные глобальные функции `Squad/Actor/Entity/Vehicle/Move/Order/Attack/Capture/Spawn/...`;
- статически проверяет известные Lua-файлы NEU;
- пытается оборачивать видимые функции `BotApi.Commands` и записывать реальные вызовы в `game.log` с префиксом `[NEU-CMD-PROBE]`;
- неизвестные команды автоматически НЕ выполняет.

Offline scanner рекурсивно анализирует распакованные `.lua/.inc/.script/.set/.mi` и формирует `.json` + `.txt` каталог найденных вызовов. Для полного исследования его следует запускать отдельно по NEU, Cold War и распакованным оригинальным скриптам игры.

### Уже подтверждено текущим NEU-кодом

- `BotApi.Commands:Spawn(...)` используется для вызова подразделений.
- `BotApi.Commands:CaptureFlag(squadId, flag)` используется как основной приказ движения/захвата.
- `BotApi.Scene:IsSquadExists(id)` используется для проверки существования отряда.
- В `v1.22` произвольное координатное движение не считается штатно подтверждённым BotApi; используется только необязательный `NEU_EngineMove`, если внешний мост реально присутствует.

## Следующий эксперимент

Запустить бой с новым probe и сохранить `game.log`. Для анализа отфильтровать строки `NEU-CMD-PROBE`. По ним составить таблицу: обнаруженная функция -> источник -> удалось ли hook -> реальные аргументы -> подтверждено ли выполнение в игре. Затем отдельно прогнать `tools/scan_bot_commands.py` по распакованным оригинальным и Cold War скриптам и сравнить результаты с runtime.
