# NEU Infantry Portraits — Broken Arrow

Публичные исходники каталога 46 отрядов NEU. Файлы изображений: `images/` (10 черновиков, 36 ещё отсутствуют).

- Сайт: `index.html` (поддерживает открытие локально, получает картинки с GitHub).
- JSON-манифест: `manifest.json`.
- Все PNG: 816×548, пиксель ММ-14, без бронетехники.
- Отметки правок/принятия хранятся **только локально в браузере**. Для передачи замечаний — экспорт JSON/CSV, затем прикрепить файл в чат.

**Важно:** опубликованные варианты пока НЕ проверены на точное соответствие вооружению.

При добавлении новых изображений загрузить PNG в `images/`, прописать его имя в `manifest.json` и в каталоге `index.html`. Путь к `raw.githubusercontent.com/.../main/NEU-Portraits/images/` остаётся стабильным.
