# NEU Infantry Portraits — Broken Arrow

Публичный каталог 46 пехотных отрядов NEU.

- Сайт: https://mockbu41.github.io/nobody-except-us-2.0.26/NEU-Portraits/
- Исходники: `index.html`, `uploader.js`, `fallbacks.js`.
- Каталог портретов: `manifest.json`.
- Изображения: `images/`, PNG 816×548.
- Все опубликованные изображения считаются черновиками до проверки пользователем.

## Как загрузить или заменить изображение

1. Откройте страницу и найдите карточку нужного отряда по имени или ID.
2. Нажмите **«Загрузить изображение»** непосредственно под картинкой.
3. Выберите PNG, JPG или WebP (до 12 МБ). Откроется предпросмотр.
4. Для публикации создайте [fine-grained personal access token](https://github.com/settings/personal-access-tokens/new) в GitHub. Выберите **только** репозиторий `MocKBu41/nobody-except-us-2.0.26` и предоставьте разрешение **Repository permissions → Contents → Read and write**. Не выдавайте остальные разрешения без необходимости.
5. Вставьте токен в поле на сайте и нажмите **«Опубликовать на GitHub»**. Для следующих изображений в этой вкладке повторно вводить токен не нужно.
6. Страница покажет ссылку на созданный коммит. После публикации GitHub Pages изображение станет доступно другим посетителям сайта.

Файл приводится к формату PNG 816×548 **без обрезки и растягивания**; если пропорции отличаются, добавляются поля. Уже существующий PNG перезаписывается по прежнему имени, а новый сохраняется с ID отряда в названии.

Публикация выполняется напрямую через [GitHub Contents API](https://docs.github.com/en/rest/repos/contents), без собственного сервера. Файл и `manifest.json` изменяются **последовательно, двумя коммитами**. Если второй коммит не удался, сайт покажет ошибку: повторите загрузку, чтобы зарегистрировать портрет в каталоге. Имя изображения, SHA и новая `revision` записываются в `manifest.json`.

**Безопасность:** токен не включён в исходники и не записывается в `localStorage` или `sessionStorage`. Он остаётся только в оперативной памяти открытой вкладки и отправляется браузером непосредственно на `https://api.github.com`. Не публикуйте токен в чате, скриншотах или коммитах. При необходимости отзовите его в настройках GitHub.

Отметки «Принято», «Требует правок» и замечания сохраняются локально в браузере. Их можно экспортировать в JSON/CSV и импортировать на другом устройстве. Загрузка нового изображения не удаляет текст замечаний; статус ранее проверенного портрета возвращается в черновики.

**Важно:** публикация файла не означает, что его вооружение и внешний вид проверены на соответствие комплектации.
