Проверка оружия: 11 изображений пока имеют статус черновиков — формы оружия и соответствие списку ещё требуют вашей оценки. Не путать «изображение загружено» и «изображение принято».

Под каждой иконкой находится кнопка «Загрузить изображение». Для публикации PNG в GitHub нужен ограниченный токен с правом Contents: Read and write; он не хранится на сайте. Загружаемые файлы приводятся к PNG 816×548 без обрезки. При замене портрета прежний файл обновляется.

Отметки и замечания сохраняются в вашем браузере (localStorage). Они не отправляются на GitHub автоматически. Для передачи исправлений используйте «Экспорт правок JSON» и прикрепите файл в чат. Если вы открываете сайт на другом устройстве, импортируйте сохранённый JSON.

Изображения: PNG 816×548, камуфляж ММ-14, без бронетехники, мягкий фокус. Источник: NEU-0.11.13 — отряды и вооружение(2).md.
