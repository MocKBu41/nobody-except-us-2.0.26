# v1.23.1 — исправление выбора карты и проверка вылета при первом спавне

На основе v1.23. Снимок полного комплекта; новые манёвры по-прежнему требуют адаптера.
Источник: LOG/game.log. Lua загрузился, первый Spawn vehicle_supporter(ukr) вернул успех; затем нативный EXCEPTION_ACCESS_VIOLATION в render_context, commit.anm. Точная причина нативного вылета по одному логу не установлена.

## Изменено

- Первый спавн разрешается на третьей игровой секунде, после выхода из GameStart. Это проверяемый обход возможного сбоя инициализации, НЕ доказанное исправление анимации.
- Перед каждым Spawn записываются время, роль и имя юнита. Можно увидеть вызов, который не вернулся.
- Для повтора именно этого испытания MapKey явно задан как 3vs3/3vs3_country. В логе загружается эта карта, но прежний подбор по названиям флагов выбрал 4vs4_cw_russian_village.
- Автовыбор больше не выбирает произвольную карту среди нескольких с теми же флагами. При неоднозначности координаты отключаются, обычные приказы по именам флагов сохраняются.
- При первой успешной записи снимка выводится VISUALIZER FILE с путём файла.

## Установка и проверка

Скопировать все bot*.lua и оба JSON из этой папки в:
mods/nobody except us 2.0.26/resource/script/multiplayer/
Открыть новый матч на 3vs3_country.

При выборе ДРУГОЙ карты заменить MapKey в bot.data.lua точным ключом этой карты из _flag_points_final.json. Можно задать nil для строгого автовыбора; если он неоднозначен, геометрии не будет.
Нельзя оставлять MapKey=3vs3/3vs3_country при игре на другой карте: одинаковые имена флагов не позволяют выявить такую ошибку пользователя.

Для визуализации открыть bot_visualizer.html, выбрать созданный игрой bot_routes_<номер>.json. Это не game.log и не справочники _map_points_index/_flag_points_final.
После старта в game.log искать VISUALIZER FILE, затем SPAWN BEGIN time=3.
Если вылет повторится после vehicle_supporter(ukr), гипотеза о раннем спавне не подтверждается; потребуется сравнение с ручным вызовом этого отряда и разбор его модели/анимаций.

Lua-синтаксис проверен в режиме 5.1. В GEM2 этот пакет ещё не запускался.

Исходный лог: ../archive/game_v1_23_a08b2b81.log
