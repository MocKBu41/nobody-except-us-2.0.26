# Бой 7 — BOT vs BOT

Версия в тесте: v1.27. Карта игры по game7.log: `multi/4vs4/4vs4_forest:battle_zones`.

## Главные проблемы

1. Старый map matcher ошибочно выбрал `4vs4/4vs4_cw_russian_village` с ratio=1.000 для обеих сторон. Причина: совпадение по именам флагов f1..f11 не является уникальным идентификатором карты. Геометрия v1.27 в этом бою недостоверна.
2. Каждый бот поставил pointstart на все 11 нейтральных флагов. Это создало очередь спавна и серию `SPAWN FAILED role=pointstart`.
3. На 30/60/90 сек обе стороны имели 0/0 захваченных флагов; открытие слишком медленное.
4. На 120 сек одна сторона ещё была в opening, другая уже собрала две БТГ и обе выбрали f9. Старый фильтр не запрещал двум группам атаковать один hostile-neutral target.
5. На 150 сек состояние всё ещё асимметрично: одна сторона opening, другая обеими группами атакует f9.
6. На 210 сек счёт владения был 0/2 против 2/0. У более успешной стороны группы разрослись до I5/I4 из-за автоматического принятия unmatched/passenger squads.
7. `NEU_TacticalAdapter`/coordinate bridge отсутствует. Фактические X/Y squad неизвестны; прежняя карта показывала расчётные, а не измеренные координаты.
8. telemetry7 = 4,469,487 байт уже для короткого боя. Причина — повторное хранение больших массивов маршрутов в snapshot.

## Что перенесено в v1.30.1

- Логика приоритетов флагов по текущему состоянию фронта, по идее VAHA BOT.
- Приказы имеют cooldown; нет постоянного CaptureFlag spam.
- Только 3 opening cappers вместо 11.
- Две ударные группы получают по 2 пехотных squad + танк с высоким spawn priority.
- Разные группы штрафуются за выбор одной цели.
- Приоритет: потерянный свой флаг > вражеский > нейтральный.
- Автоматическое принятие unmatched squad отключено, чтобы экипажи/пассажиры не раздували БТГ.
- После неудачной волны группа быстро меняет/пересчитывает цель.
- Геометрия карты отключена до получения достоверного runtime map ID. Неверные X/Y больше не используются в принятии решений.
- Compact telemetry: один snapshot/15 сек; маршруты и точки не дублируются; отдельный файл на команду; hard cap 4.5 MB.
