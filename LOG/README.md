# LOG — испытания бота NEU

Эта папка предназначена для хранения логов испытаний бота.

## Как использовать

Загружай сюда логи после каждого испытания. Желательно сохранять исходное имя файла с датой/временем, например:

`game(20260914-173743).log`

По этим логам будем делать отчёты по испытаниям: ошибки загрузки/скриптов, вызов юнитов, движение отрядов, остановки, маршруты и координаты, работа с flag_point/SpawnPoint, высадка пехоты, распределение бойцов, атака разных направлений, поведение танков/БМП и другие события бота.

## Правило проекта

Логи из этой папки считаются историей испытаний. При последующих разборах нужно сравнивать новый лог с предыдущими логами из `LOG` и учитывать найденные ранее проблемы и изменения поведения бота.
